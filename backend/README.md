# MedStore — Backend

Production-grade **FastAPI** backend for a wholesale pharmacy management system.

**Stack:** Python 3.11+ · FastAPI · SQLAlchemy 2.0 (async) · Alembic · PostgreSQL 16 · Pydantic v2 · fastapi-users (JWT) · WeasyPrint (PDF) · pytest.

---

## Features

- **JWT auth** via `fastapi-users` with role-based dependencies:
  `get_current_user()` (any active user) and `get_current_admin()` (admin only).
- **Atomic writes** — every sale/restock/inventory mutation runs inside an async
  DB transaction.
- **Sale discount rule** — 5% per-line discount when `quantity_strips >= 2`;
  stock deducted atomically; **HTTP 400** on insufficient stock.
- **Restock** — admin-only; increments stock and records a restock invoice.
- **Race-safe invoice numbering** — `INV-SALE-0001` / `INV-RESTOCK-0001` using a
  per-type counter row locked with `SELECT ... FOR UPDATE`.
- **PDF invoices** — Jinja2 HTML template rendered by WeasyPrint, streamed as
  `application/pdf`.
- **Dashboard aggregates** — today's revenue/transactions (+ day-over-day %),
  low-stock count, total inventory value, 7-day sales trend.
- **CORS** configurable per `.env`.
- Tooling: **ruff + black + mypy** (pre-commit), **pytest** suite, multi-stage
  **Dockerfile** (non-root, gunicorn + uvicorn workers).

## Local setup

### 1. Prerequisites

- Python 3.11+
- PostgreSQL 16 (or use the bundled `docker-compose.yml`)
- For PDF generation locally, WeasyPrint's native libs (pango, cairo,
  gdk-pixbuf). The app degrades gracefully (HTTP 503 on the PDF route) if they
  are absent — everything else works.

### 2. Configure environment

```bash
cd backend
cp .env.example .env
# Edit .env: set JWT_SECRET, DATABASE_URL, CORS_ORIGINS, FIRST_ADMIN_*
```

### 3. Install dependencies

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### 4. Run database migrations

The initial migration **creates all tables, seeds the two invoice counters, and
seeds one admin user** (`FIRST_ADMIN_EMAIL` / `FIRST_ADMIN_PASSWORD` from `.env`).

```bash
# Apply all migrations
alembic upgrade head

# Roll back one step
alembic downgrade -1

# Create a new autogenerated migration after model changes
alembic revision --autogenerate -m "describe change"
```

### 5. Start the server

```bash
# Development (hot reload)
uvicorn app.main:app --reload --port 8000

# Production (gunicorn + uvicorn workers)
gunicorn app.main:app -c gunicorn_conf.py
```

Health check: `GET http://localhost:8000/health`.

## Docker

```bash
# Build
docker build -t medstore-backend ./backend

# Run (expects a reachable Postgres in DATABASE_URL)
docker run --rm -p 8000:8000 \
  -e DATABASE_URL=postgresql+asyncpg://medstore:medstore@host.docker.internal:5432/medstore \
  -e JWT_SECRET=change-me \
  -e CORS_ORIGINS=http://localhost:3000 \
  medstore-backend
```

The container entrypoint runs `alembic upgrade head` (set `RUN_MIGRATIONS=0` to
skip) and then launches gunicorn as a non-root user.

### One-command stack (API + Postgres)

```bash
cd backend
docker compose up --build
```

## Testing

Tests run against an in-memory **SQLite** database (no Postgres required) and
cover: sale discount logic, insufficient-stock rejection, stock deduction,
restock increment, invoice numbering, invoice HTML/PDF rendering, and the auth/
API flow.

```bash
source .venv/bin/activate
pip install -r requirements.txt   # includes pytest deps
pytest -q
```

> The single PDF *byte* test self-skips when WeasyPrint's native libraries are
> not installed; the HTML rendering it depends on is always tested.

## Notes for integrating with the frontend

The frontend expects `application/pdf` from `/api/v1/invoices/{id}/pdf` — this
backend provides exactly that. Point the frontend's `NEXT_PUBLIC_API_URL` at this
service and set `NEXT_PUBLIC_USE_MOCK_API=0`. The seeded admin credentials come
from `FIRST_ADMIN_EMAIL` / `FIRST_ADMIN_PASSWORD`.
